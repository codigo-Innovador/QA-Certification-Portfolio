# QA Test Cases

This folder contains test cases developed as part of my QA certification coursework and hands-on software testing practice.

## Test Case Files

| File | Description |
|---|---|
| `Smoke-Test-Cases.csv` | 10 smoke test cases designed to verify critical application functionality. |
| `Master_Regression_Suite.csv` | Master regression suite containing 50 test cases covering existing application functionality. |
| `selected-regression-test-cases-v2.5.1.csv` | 10 regression test cases selected from the master suite based on the v2.5.1 release notes. |

## Smoke Testing

The smoke testing suite contains 10 test cases designed to verify critical application functionality and determine whether the application is stable enough for further testing.

## Regression Testing

The Master Regression Suite contains 50 test cases covering existing application functionality.

For the v2.5.1 release, I reviewed the release notes and selected 10 relevant test cases from the master suite. These selected cases were imported into Zephyr Essential for test management.

This exercise demonstrates the ability to:
- Review software release notes.
- Identify relevant regression test cases.
- Select tests based on release changes.
- Organize and manage test cases using a test management tool.

## Testing Documentation

Test case documentation includes:
- Test case IDs
- Test descriptions
- Test priorities
- Preconditions
- Test steps
- Expected results
