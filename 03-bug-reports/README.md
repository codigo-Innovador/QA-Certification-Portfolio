# QA Bug Reports

This folder contains bug reports created as part of my QA certification coursework and hands-on software testing practice.

## Bug Reports

### MindBridge Education — Checkout 404 Error (Microsoft Edge)

This bug report documents a checkout failure in a simulated online learning application. Selecting "Place order" in Microsoft Edge results in a 404 Not Found error instead of the expected order confirmation page.

The report includes:
- Detailed environment information
- Step-by-step reproduction instructions
- Expected and actual results
- Severity and priority assessments
- Cross-browser testing observations
- Screenshot evidence
