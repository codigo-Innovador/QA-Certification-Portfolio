# QA Test Execution

This folder contains QA documentation demonstrating test planning, test execution, environment preparation, defect management, and evidence collection.

## Projects and Deliverables

### QA Strategy and Execution Plan

This document includes:

- RACI Matrix – Defines project roles and responsibilities.
- STLC Strategy – Outlines the Software Testing Life Cycle.
- Test Environments – Documents testing environments and configurations.
- BDD Acceptance Criteria – Defines expected application behavior.
- Defect Log – Tracks identified defects and their status.
- Execution Evidence – Provides supporting evidence of test execution.

## Skills Demonstrated

- QA strategy and planning
- Test environment management
- Behavior-Driven Development (BDD)
- Defect tracking and reporting
- Test execution and documentation
