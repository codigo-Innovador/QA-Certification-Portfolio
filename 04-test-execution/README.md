# QA Test Execution

This folder contains QA documentation demonstrating test planning, test execution, environment preparation, defect management, and evidence collection.

## Projects and Deliverables

### QA Strategy and Execution Plan

This document includes:

- RACI Matrix – Defines project roles and responsibilities.
- STLC Strategy – Outlines the Software Testing Life Cycle.
- Test Environments – Documents testing environments and configurations.
- BDD Acceptance Criteria – Defines expected application behavior.
- Defect Log – Tracks identified defects and their status.
- Execution Evidence – Provides supporting evidence of test execution.

### MindBridge Cross-Browser / Device Compatibility Report

This report documents compatibility testing for the MindBridge Education simulated learning application using Microsoft Edge Developer Tools and mobile device emulation.

The report includes:

- Desktop and mobile viewport testing configurations.
- Pass/fail results across different viewport sizes and authentication states.
- Identification of a navigation defect affecting authenticated users on screens below 400px.
- Step-by-step defect reproduction instructions.
- CSS inspection using browser DevTools to investigate `pointer-events: none`.
- Severity assessment and recommendations for regression testing.
