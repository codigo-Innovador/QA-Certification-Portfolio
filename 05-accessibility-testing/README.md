# Accessibility and Usability Testing

This folder contains accessibility and usability testing documentation developed as part of my QA certification coursework.

## Accessibility and Usability Summary — Lab 2

This assessment evaluates accessibility issues and usability improvements in the MindBridge web application.

### Accessibility Findings
- Missing alternative text on course images (WCAG 1.1.1 — Non-text Content, Level A).
- Insufficient text contrast on interface elements (WCAG 1.4.3 — Contrast Minimum, Level AA).

### Usability Recommendations
- Improve registration wizard instructions and progress indicators.
- Provide clearer, more actionable error messages during registration.
